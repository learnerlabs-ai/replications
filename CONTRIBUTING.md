# Contributing

This repository exists to be checked, so the most useful thing you can send is a result.

## Replication reports are welcome

Run a demonstration on your own key and open an issue with what you got. Include the folder you
ran, the date, and the numbers you saw next to the numbers published here. A run that disagrees
with ours is more interesting than one that agrees, and we would rather hear it from you than
find it later.

Two things make a report easy to act on. Say which stages trained during your run, because two of
the five load a learner that already holds the setup and only run the demonstrated step live.
And paste answers in full rather than summarising them, since a summarised answer cannot be
regraded.

## Issues are welcome

Corrections to the data, the questions, the expected answers or the arithmetic. If a question is
ambiguous, or an expected answer is defensible in a wording we marked wrong, that is worth an
issue: our grader is deliberately strict and blunt, and where it scored something oddly we would
rather say so in the README than leave it.

## What we will not merge

Model code, training code or serving code, in any form and from any source. None of it is in this
repository and none of it will be.

Re-runs submitted as replacements for the published sessions. The recorded runs are the evidence.
A better run is a new result reported alongside them, never an edit over the top of them.
